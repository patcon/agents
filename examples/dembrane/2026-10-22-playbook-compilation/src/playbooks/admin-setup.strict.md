# Portal Setup

## Basics

- Which language will participants speak? Pick one: English, Dutch, German, French, Spanish, Italian, Ukrainian, Czech (options in two columns)
- What must be provided before each portal conversation? Pick any: A name, An email (optional)
- Can participants ask to be emailed when the report is ready? Pick one: Yes, No (optional, only if "An email" is selected)
- Which tutorial should participants see first? Pick one: None, Basic, Advanced
- Which tags can participants pick from? Separate them with commas. (optional)

## Participant features

- Should participants be able to use Explore? Pick one: Yes, No
- Which Explore mode? Pick one: Summarize, Brainstorm, Custom (only if Explore is enabled)
- What should Explore's custom reply prompt say? (only if Explore mode is Custom)
- Should participants be able to use Verify? Pick one: Yes, No
- Which topics should Verify check? Pick at least one. Pick any: Actions, Agreements, Disagreements, Gems, Moments, Truths (only if Verify is enabled)
- Remind participants to verify when they finish? Pick one: Yes, No (optional, only if Verify is enabled)

## Portal content

- What's the portal page's title?
- What should the portal page say? (optional)
- What should participants see when they're done? (optional)

## Advanced

- Any key terms the transcriber should know? Separate them with commas. (optional)
- Anonymize transcripts? Pick one: Yes, No
- Generate conversation titles and tags automatically? Pick one: Yes, No
- How should titles be written? (optional custom prompt) (optional, only if automatic title and tag generation is enabled)
